## Language learning in context

This app helps language learners build vocabulary from texts they choose.

Choose a learning language the first time you use the app. To change it later, use the learning-language control in the top bar. The top bar also links directly to your vocabulary and About. Supported languages are German, English, Catalan, Vietnamese, Chinese (Simplified), Arabic, Urdu, Russian, Hindi, French, Spanish and Filipino. English is the default interface language; the interface follows the selected learning language.

With the app, you can:

- Paste or enter texts, keep several open in tabs, close tabs without deleting their saved texts, and reopen them from the text manager. Delete saved texts you created; the welcome text is protected.
- Edit a saved text and click a word to open its definition and examples.
- Select a sentence to reveal its playback controls in a reserved space, so moving between sentences does not shift the text. Play reads from the active sentence through the rest of the text; the repeat icon switches Play to sentence-only mode.
- Mark vocabulary as new, learning or learned.
- Add definitions and usage examples.
- Edit, import and export a separate vocabulary list for each learning language using CSV.
- Save vocabulary and example images in your browser.

Word segmentation follows the selected language, including Chinese text that does not use spaces between words. Arabic and Urdu text is displayed right to left. The app uses the browser's speech synthesis when available.

Texts, vocabulary and example images are stored locally in the current browser. They are not synchronized across devices.
